# 숫자쓰기 ✏️

아이패드에서 손가락이나 애플 펜슬로 숫자 쓰기를 연습하는 웹 앱입니다.

## 사용 방법

`index.html`을 iPad Safari(또는 아무 브라우저)에서 열면 바로 실행됩니다.
빌드 과정이나 별도 설치가 필요 없는 순수 HTML/CSS/JavaScript 앱입니다.

GitHub Pages로 배포하려면 저장소 설정에서 Pages를 이 브랜치(또는 배포 브랜치)의
루트로 지정하면 됩니다.

## 화면 구성

- **왼쪽**: 숫자만큼의 사물(이모지)을 보여줍니다.
- **오른쪽**: 큰 숫자의 점선 윤곽선과 쓰는 방향을 알려주는 화살표가 표시됩니다.
  손가락이나 펜슬로 따라 그리면 색이 윤곽선 안쪽에만 칠해지고 바깥으로는
  나가지 않습니다.
- **하단**: 색상 팔레트와 지우기 / 완료 버튼이 있습니다.

## 학습 단계

1. **1단계** — 1부터 10까지 순서대로, 두꺼운 점선 윤곽선 제공
2. **2단계** — 1~10 무작위 순서, 두꺼운 점선 윤곽선 제공
3. **3단계** — 1~10 무작위 순서, 얇은 점선 안내선만 제공
4. **4단계** — 1~10 무작위 순서, 안내선 없이 자유롭게 쓰기

각 숫자를 다 칠하고 "완료!"를 누르면 반듯한 숫자 모양으로 바로잡아 보여주며
"잘했어요!" 칭찬 메시지와 함께 다음 숫자로 넘어갑니다.
